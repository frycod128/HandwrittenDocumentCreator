# A3 随机手写字体文档生成器

读取长文本、手写字体选择列表和每栏行数，输出 A3 横向双栏文档。每个非空白字符从所选字体中随机取一种，独立旋转 `-10°` 到 `+10°`，并在横向和纵向各随机移动最多 `5%` 字高。

## 已支持的素材

- `字体素材/*.gfont`：奎享单线字库，共 80 个文件。
- `A3空白文档.docx`：版式依据为 A3 横向、四边 12.7 mm 页边距、双栏、栏间距 7.5 mm。
- `.gfont` 使用文件末尾内嵌 ZIP 中的逐字矢量笔画，不依赖系统安装同名字体。

## 启动

Windows 下双击 `run_gui.bat`。首次运行会自动在项目内准备环境，无需预先安装任何东西（需要联网）：

1. 依次查找项目内 `.python`、项目内 `.venv`、`py -3`、PATH 上的 `python`；
2. 都找不到时，把官方独立构建的 Python 3.13 下载到项目内 `.python`（约 47 MB），并按固定 SHA-256 校验；
3. 用找到的 Python 在项目内创建 `.venv` 并安装 `requirements.txt`。

之后每次启动只做一次快速自检，环境完好就直接打开界面；已有 `.venv` 时不会重建，只会补齐缺失的依赖。想重建环境时删除 `.venv` 后重新运行即可。整个过程只写项目目录（`.venv`、`.python`、`.cache`）：不安装全局包、不修改 PATH、不写注册表，也不影响其他用户。

其他平台或需要手动控制时：

```powershell
python tools/bootstrap.py --launch-gui   # 图形界面
python tools/bootstrap.py --check        # 只检查环境，不改动文件
python tools/bootstrap.py --python D:\Python311\python.exe   # 指定基础解释器
```

界面中可粘贴长文本、搜索字体并通过复选框多选、设置每栏行数、随机种子与输出位置。字体列表会动态扫描 `字体素材`，显示复选框、字符数和完整文件名；单字正方形预览始终使用最后勾选的字体。默认可同时生成：

- A3 横向 PDF：矢量笔画，逐字变换完全准确。
- A3 横向 DOCX：每页以高清图片嵌入，版式与 PDF 一致。Word 对“数万个独立旋转字符”的原生支持不稳定，因此 Word 版采用页面图。
- A3 横向纯图片 PDF（可选）：把矢量 PDF 逐页按 300 dpi 截图后重新装订成 PDF。打印兼容性最好，但页面只有位图，文字不能再放大或选中。

取消勾选“生成 PDF（矢量精确版）”时，矢量文件只作为纯图片 PDF / Word 的中间稿临时生成，转换完成后自动删除，不会留在输出目录；此时必须保留纯图片 PDF 或 Word 中的至少一种。

## 输出位置

默认输出目录是当前计算机的“下载”文件夹：Windows 依次通过 Known Folder API 和注册表解析（支持被重定向到其他磁盘），其他系统读取 XDG `user-dirs.dirs`；只有在“下载”文件夹不存在且无法创建时才退回项目内的 `output/`。界面里可以随时改成别的目录；命令行省略 `--output` 时也写入这个默认目录。

生成前会实际试写一次来确认目录可写。若不可写（权限不足、目录只读、被安全策略拦截等），程序会弹窗让你选择：**以管理员身份重试**（会弹出 Windows 授权窗口，正文会自动带到新实例）、**改用可写目录**（并把“输出目录”同步改成该目录），或取消；不会静默丢到别处。命令行是非交互的，遇到不可写会打印提示并改用可写目录。

## 命令行

```powershell
.\.venv\Scripts\python.exe main.py `
  --input .\examples\示例输入.txt `
  --fonts "常用_kvenjoy_美文.gfont" "超连笔快写-3500字_kvenjoy_gantry.gfont" "楷体_kvenjoy_大孔龙.gfont" `
  --lines 52 `
  --output .\output\示例手写文档.pdf `
  --docx `
  --image-pdf `
  --seed 20261112
```

查看字体及字符覆盖：

```powershell
.\.venv\Scripts\python.exe main.py --list-fonts
```

## 配置文件

界面启动时会在项目根创建 `settings.json`，记录界面上所有复选框与输入框的状态（字体勾选、每栏行数、随机种子、输出目录、文件名、PDF/纯图片 PDF/Word 开关、字体搜索词、预览字符），**不记录“待排文字”正文**。文件缺失、损坏或字段不合法时会立即重建为默认配置；界面上的修改约 0.4 秒后自动写入，关闭窗口时再写一次。删除该文件即可恢复默认设置。

### 文件名模板

“文件名”输入框支持占位符，生成时才展开，因此同一个模板可以反复使用而不会覆盖上一次结果：

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{Time}` | 生成时间，格式 `YYYYMMDDHHMMSS` | `20261125191301` |
| `{Seed}` | 本次生成使用的随机种子 | `899010234` |
| `{LineCount}` | 每栏行数 | `52` |
| `{FontsCount}` | 选中的字体数量 | `5` |

默认值为 `手写文档_{Time}`。可以自由组合，例如 `手写文档_ {Time}  {LineCount}` 会得到 `手写文档_ 20261125191301  52.pdf`；想在数字后面带上“行/line”就直接写进模板（如 `{LineCount}行`）。未识别的占位符和普通文字原样保留，文件名中不允许的字符会替换成 `_`。

## 排版规则

- 每页固定两栏，左右栏都按输入的“每栏行数”划分。默认 52 行，建议实际使用范围 46–58 行。
- 文本按左栏自上而下、右栏自上而下、再进入下一页的顺序流动。
- 字号由页面可用高度和每栏行数计算，并根据 10° 旋转与 5% 位移预留安全空间。
- 中文按接近全角宽度排版，英文、数字与标点按实际笔画宽度排版。
- 所有 `.gfont` 单线笔画在纸面上固定为 `0.5 mm` 外层宽度，不随字号或每栏行数缩放；边缘以低透明度收窄叠层模拟圆珠笔轻微沁润，中心保持实黑。
- 明示换行会保留；自动换行只发生在字符之间。
- 所选字体都不包含某个字符时，使用系统楷体/黑体回退，并在生成结果中报告数量。

## 纯图片 PDF（打印兼容）

部分打印机、打印服务和虚拟打印机驱动处理不了包含数万个独立矢量笔画对象的 PDF，会把页面印成空白或直接拒绝。勾选“同时生成纯图片 PDF（打印兼容）”后，程序先临时生成矢量 PDF（勾选了矢量 PDF 时保留，否则转换后删除），再把每一页按 300 dpi 渲染成灰度位图，重新装订成一个新的 PDF：

- 文件名在原名后加 `_纯图片`，例如 `手写文档_20261126103000_纯图片.pdf`，不会覆盖矢量版。
- 页面尺寸与矢量版一致，每页只有一张整页位图，不含字体或矢量对象，绝大多数打印机都能识别。
- 代价是文字不能再放大、搜索或选中；需要高保真或后期编辑时继续使用矢量版。
- 位图页面通常比矢量版更大，页数多时文件体积会明显上升；`--image-pdf-dpi` 可以调低分辨率（范围 72–600，默认 300）。

命令行使用 `--image-pdf`：只写该选项时自动在 PDF 文件名后加 `_纯图片`，也可以显式给出路径。
